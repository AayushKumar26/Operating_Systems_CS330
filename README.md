# Operating Systems

This repository serves as a collection of coursework materials for the CS330 Operating Systems course. It includes various labs and projects that explore fundamental concepts in operating systems.

## Labs

The lab assignments are designed to provide hands-on experience with essential operating system functionalities. Each lab focuses on specific topics, such as process management, memory management, file systems, and more, allowing students to gain practical skills and insights into system-level programming.

## Projects

In addition to labs, this repository contains several projects that delve deeper into operating systems concepts. These projects often involve implementing aspects of an operating system, working with real-time systems, or exploring advanced topics like concurrency and deadlock management. Each project aims to reinforce the understanding of theoretical concepts through practical application.

Feel free to explore the various materials and enhance your learning experience in operating systems!
