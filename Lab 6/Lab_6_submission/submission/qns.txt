Ans.    if(config_hack_semantics(DIV_ZERO_USH_EXIT, &a) == 0){
		printf("testcase failed\n");
		exit(0);
	}

Q1. What all registers are changed in do_div_by_zero and why?
Ans.	 regs->entry_rip=*((u64*)(regs->rbp+8));
         regs->entry_rsp=(regs->rbp)+16;
         regs->rbp=*((u64*)regs->rbp);
         regs->rax =1;
	 The registers changed are:
	1. entry_rip -> sets pc to return address of parent function so that execution resumes in the parent funcion at the point of return
	2. entry_rsp -> sets stack pointer to the topmost address of parent function, reducing stack size and wiping out current functions stack
	3. rbp -> restores the old value of rbp which is stored at the address that rbp currrently points to.
	4. rax -> sets return value of curent function to 1
